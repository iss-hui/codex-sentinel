# Sentinel 第一轮设计探索

日期：2026-10-19。仅设计，尚未获准实现。

## 项目理解

Codex Sentinel 是本地优先的 Codex 使用时间管理桌面助手。它读取本地会话日志、只读 SQLite 索引及模型缓存，呈现限额记录，按记录的重置时间与缓冲安排恢复或轻量激活，通过官方 CLI 执行。它不决定服务器额度，也不保证一条消息开启新窗口。

技术栈：Python 3.10+、PySide6 6.7+、psutil。五页使用 QStackedWidget，每页由 QScrollArea 包裹。当前默认窗口 1160 × 820，最小 940 × 700。界面支持中英文、系统托盘、任务通知与更新窗口。

页面结构：

| 页面 | 当前功能 |
| --- | --- |
| 总览 | 限额分组、五小时与周/次窗口、恢复最新中断、持续激活、设置、日志 |
| 窗口启动与预约 | 新建/已有对话、模型、目录、消息、权限、尽快/定时/重置点、提前 2/3 小时 |
| 执行队列 | 添加、编辑、排序、删除、重新排期、暂停、停止、详情与 CLI 日志 |
| 本地对话 | 搜索、标题/ID、模型、目录、Token 记录、更新时间、状态、轮次 |
| 设置 | 语言、扫描间隔、宽限、接管桌面、托盘、通知、声音、更新、路径 |

选择总览，因为它最能表达“限额 → 等待 → 恢复/激活”的核心体验，也能先验证导航、信息层级、常驻状态和设置交互的整体方向。

检查依据：README_zh.md、pyproject.toml、gui/main_window.py、gui/pages 下全部五页、gui/app.py、config.py、scripts/render_gui.py，以及现有总览截图。仓库原有未提交改动已记录在 baseline-status.txt，未改动这些文件。

## 三版方向

| | A 焦点驾驶舱 | B 时间航线 | C 精密工作台 |
| --- | --- | --- | --- |
| 导航 | 文字侧栏 | 顶部导航 | 紧凑导航轨道 |
| 信息骨架 | 恢复任务主面板 + 限额侧面板 | 限额横条 + 时间轴/恢复详情 | 限额/目标/设置三栏 + 记录表 |
| 首要问题 | 接下来恢复什么？ | 什么时候继续？ | 执行依据与配置是否正确？ |
| 设置交互 | 按需打开弹窗 | 按需打开弹窗 | 常驻右侧检查器 |
| 信息密度 | 中 | 中低 | 高 |
| 推荐人群 | 大多数日常使用者 | 重视时间规划者 | 高频操作、诊断者 |

推荐 A：符合常驻后台桌面助手定位，任务清晰且操作稳定；移植至现有 Qt 布局的风险较低。后续可以讨论吸收 B 的时间表达、C 的记录可见性，当前保留三版独立性以便判断。

## 桌面适配与实现约束

- 按现有默认 1160 × 820、最小 940 × 700 检查；更小宽度也会重排，而不是整体缩放字体。
- A 最小窗仍保留任务与限额并排，缩短次要微型时间线；B 最小窗保留纵向时间线，紧凑配额说明；C 保持三栏并精简次要元数据。
- 800px 以下作为额外浏览器预览适配：A 上下堆叠；B 时间线折叠但保留关键时间；C 检查器移到下方。正式 App 现有限制仍是 940px。
- 最小窗口允许纵向滚动，与现有 QScrollArea 一致；不通过整体缩放压缩页面。C 的记录表在最小窗口位于首屏下方，目标、限额与设置依旧并排可操作。
- 普通文字、路径、时间、状态均可用 QLabel/QLineEdit；排版可用 QHBoxLayout/QVBoxLayout/QGridLayout，模式可用 QStackedWidget，历史可用 QTableWidget/QDialog，滚动沿用 QScrollArea。
- 原型的分栏不要求 WebView、浏览器运行时、新依赖或新框架。仅将其作为后续 Qt 设计参考。
- 本轮不设计全量异常状态、更新详情、运行中停止状态和其他四页。未知与过期记录后续必须保留现有语义，不能当作 0%。

## 打开方式

双击 index.html 打开对比入口，a.html / b.html / c.html 可分别独立打开。整个目录内使用相对资源，无 CDN、无网络请求、无包管理依赖、无项目配置修改。

浏览器预览使用标准库本地静态服务，绑定 127.0.0.1，仅服务此目录。如服务已结束，仍可直接打开本地 HTML。
