# A 方案原生界面实现

实现日期：2026-10-19。采用现有 Python / PySide6 Widgets，无新增依赖。

## 范围与行为

- 五个主页面使用统一的中性暗黑/白色主题、侧栏与页面层级。设计目录 round-01、round-02-neutral 保留。
- 总览采用恢复/持续激活工作区 + 本地限额侧栏，显示最近自动化结果。恢复设置移到独立窗口，保留缓冲、语句、立即保存开关与固定权限语义。
- 预约页分为任务内容与时间安排。最早执行预览复用已有本地限额阻塞计算，不改变提交数据或调度规则。
- 队列保留六列、排序、编辑、删除、重新排期、停止及原始日志。详情仍保留日志头部、目标与实际启动 ID，以及刷新时的选择和滚动位置。
- 本地对话保留七列与搜索，选中详情显示完整 ID、标题和目录。
- 设置保留语言、扫描、宽限、接管、托盘、通知、声音、数据路径、CLI 与更新选项；新增主题项。
- 更新 worker、执行器、权限、会话交接、API、状态文件和队列派发逻辑未重构。

## 主题与兼容

新增配置 `theme`：`dark`（旧配置默认）、`light`、`system`。右上角与设置中的主题选择即时保存，只更新外观，不触发扫描、不重载填写中的表单，也不清空日志选区。系统主题监听使用 Qt 现有信号。

共享样式和 QPalette 覆盖原生输入、表格、菜单及弹窗。Windows 使用可用的 DWM 深色标题栏属性；不替换系统窗口控制。Qt 控件箭头和勾选图标作为本地 SVG 资源随既有 `--collect-data codex_sentinel` 构建流程收集。
